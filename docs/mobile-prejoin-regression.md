# Mobile 入会前页面与本次回归（2026-10-15）

> 历史交付记录：2026-10-19 用户要求移除 Native PreJoin，已由[登录与“我的”原型](mobile-account-prototype.md)取代。以下 PreJoin 内容不代表当前 Native 行为，Web PreJoin 保留；创建诊断与原授权规则继续有效。

## 已实现

- 顶部左侧为箭头加“返回”按钮，仍释放本地设备并退出 PreJoin；右侧复用设置页 `SettingsSelect` 与共享 `langOptions`，可直接选择 English / 简体中文 / Русский，不再循环切换语言。

- 首页临时房间、指定名称/链接，以及会议列表手动加入，先显示 PreJoin。只有确认加入才发起创建/prepare/RTC/confirm。失败留在 PreJoin，可修改昵称重试或取消，不再直接跳到会议列表。
- Web 原 PreJoin 的内容顺序提取为 `@vocespace/ui` 的 `preJoinContent`。Web 保留原 DOM、样式和设备逻辑；App 使用 Native 控件，沿用共享 i18n 文案、主色、视频预览/音频/视频/昵称/加入布局。
- 摄像头、麦克风默认关闭，点击后仅本地采集；取消、提交、卸载和后台均释放本地轨道。迟到的系统权限结果也会释放。Web 的试听音频原样打包给 App；音量滑块控制本地试听。原生视频虚化暂不支持，控件禁用并明确说明；未接入平台账号登录。
- 确认入会后，只对服务端确认的房主应用用户主动开启的设备选择。访客不会因本地预览绕过主持人邀请。会议列表原来的有效 HLS 播放 15 秒自动加入逻辑保留；手动加入先停止 HLS，再进入 PreJoin。
- Native 为原 Web SVG 中没有 viewBox 的 LiveKit 图标补齐坐标范围和居中缩放。Web SVG 路径及渲染保持原样。
- 入会失败区分会话、创建、prepare、RTC 连接、confirm、设置读取阶段；API 错误显示状态码、错误码、请求编号。会议列表保留具体请求错误。服务端 5xx 记录相同请求编号、方法和异常类型，不记录请求正文、令牌或配置。
