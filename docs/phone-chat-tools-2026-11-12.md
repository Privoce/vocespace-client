# Phone 分享与聊天工具整合（2026-11-12）

## 实现

- Web Phone 的顶部分享与设置复制分享统一调用 `ShareInvitation`，内部使用共享 `MeetingShare`；只显示一个蓝色“复制邀请”按钮。Web 复制当前部署 origin、basePath 与编码后的 Space 名组成的链接；Native 沿用 `Clipboard` 复制 Space 名，也使用相同的共享分享视图与按钮文案。
- 去除 Web Phone 设备菜单箭头的 `left: -8px`。
- Web Phone / Native 只保留会场外层的一份聊天。展开按钮直接改变 `MeetingDock` 高度，保留聊天实例和草稿，没有聊天 Drawer 或遮罩。
- 会场不再插入工具集合 Tile；已创建的图片、网页、白板等内容 Tile 保留。共享 `MeetingToolsPanel` 在输入框下方显示四列工具，由左侧加号展开/收起，输入框聚焦时收起工具以留出软键盘空间。
- 面板包含图片、Iframe、HyperBeam、白板、文件上传和会议文件；文件上传使用 folder 图标。端内适配器继续持有原来的权限、请求、上传和播放器生命周期。
- 会议文件弹窗常驻单份聊天适配器，不再受 compact 状态限制；Web 弹窗显式使用 zIndex 1200（PhoneSheet 为 1050），Native 使用独立 Modal。
- 工具列表错误仍只后台重试，不向会场添加错误区域；文件操作和聊天发送失败保留原提示/重试路径。

## 验证

- 全项目、Mobile、共享 UI 类型检查及依赖边界通过。
- 45 个测试文件、175 项测试通过；增加聊天展开和工具面板切换保留同一输入框与草稿的回归，工具面板接入文件上传/查看的行为检查。
- 修正原有 `native-widgets` 测试夹具缺少 ParticipantSettings 默认字段导致的全项目类型错误。
- Web 标准生产构建通过；相关目录 lint 无错误，保留原有 Hook 依赖警告。
- iOS Expo JS 导出通过，不等同于 iOS 原生构建或真机验收。
- 浏览器以共享组件及隔离静态数据检查 390px 布局、无遮罩工具面板、聊天展开与草稿保留、文件弹窗和单个邀请按钮。未加入生产会议、未向服务器上传文件。
- iOS/Android 真机键盘、系统文件选择器、真实文件发送/下载仍待回归；未部署或发布新包。
