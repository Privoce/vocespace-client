# 会议 Tab：我的 / 广场

2026-10-27，按用户两张新设计图调整 Native 会议入口。

## 页面与数据

- 顶部只保留居中的我的 / 广场切换，按用户后续要求移除品牌标识及个人头像入口。页面背景复用个人 Tab 的 `accountColors.background`（`#191919`），安全区和底部 TabBar 也恢复通用配色。已登录默认「我的」，访客默认「广场」。正式会议仍复用原会议组件及上层唯一连接所有者。
- 我的页使用深色房间卡、三种房型插画和主色创建按钮；主房间以账号 username 补入并去重，其他房间读取旧平台 `space` 表。在线人数仅使用当前公开目录的真实数据，未发现时显示等待状态。
- 新增 Native `POST /api/v1/account/spaces`。服务端验证账号 Bearer 后按实际用户 ID 过滤 `owner_id`，使用用户 token 遵循 Supabase RLS，按稳定 ID 顺序分页读取。只投影 id / name / url / kind；不接受客户端传入的用户 ID，不返回服务密钥。
- 房间 URL 在 Native 通过现有地址解析器转换为当前会议服务的空间名；不会把账号或会话凭证转发到其他服务器。无效地址不能加入。
- 常规房间创建复用现有 Native 创建 / 加入流程。用户已确认「一起看」「教学」仅展示卡片并标注即将开放。本次未新增房型业务或把 Native 临时会话创建同步写入旧平台房间表。
- 广场改为圆角整页预览卡片，视频铺满、底部渐变、空间信息、人数、序号、静音按钮、加入按钮和倒计时进度。保留上下分页、错误重试与无预览占位；没有伪造电影视频、封面、人数或标签。
- 加入 Space 按钮按用户后续要求移除左侧图标，保留文字、倒计时和右侧箭头。此次样式调整的 Mobile 类型、边界和差异检查通过。
- 根据新图将自动加入阈值从 15 秒改为 10 秒，仍要求首帧和连续有效播放；加载、卡顿、不可用预览不累计。关闭自动加入时仅手动加入。
- 切换到「我的」卸载预览，离开会议 Tab 时停用预览及目录刷新；原主持人 / 设备采集退出确认保持不变。静音按钮复用本机预览声音偏好。
