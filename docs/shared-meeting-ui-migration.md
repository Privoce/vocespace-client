# 共享 Phone 会议界面：扩大迁移

2026-10-10，用户确认小范围验证完成，授权以现有 Web Phone 界面为视觉基准扩大迁移。本批覆盖会中基础界面；原小范围交付和 React 升级记录保留在 [试验记录](shared-meeting-ui-pilot.md)。

> 后续进展：用户已反馈本批基本界面可用，房间设置共享抽取见 [设置交付](shared-room-settings.md)。本文件保留原批次记录。

## 当前入口

- App：2026-10-11 起统一使用公共会议界面，移除版本开关与旧版渲染分支。首页提供「创建/加入会议」入口，会议 Tab 保持滑动预览与加入。无需新增原生模块。
- Web Phone：房间链接使用 `?meetingUi=shared`，已含参数则追加 `&meetingUi=shared`。PC 与未带参数的 Phone 保持现有入口；Web 全面替换仍需高级工具与布局回归。
- `/labs/meeting-ui`：纯本地静态验证，可切换 2 / 6 个成员、翻页、放大、成员列表、更多菜单和聊天草稿。麦克风按钮只切换演示状态，不采集设备；消息只存页面内存，不发送至会议。

## 已迁移的共享部分

| 模块 | 单份实现 | 端内适配 |
| --- | --- | --- |
| 顶栏与舞台 | 紧凑标题、在线状态、按可用高度计算的卡片、分页、共享屏幕焦点 | Web 复制名称；App 调用系统分享；真实轨道由各自 VideoTrack 呈现 |
| 成员卡片 | 圆角深色卡片、圆形头像与眼睛、发言圈、静音/姓名/角色/状态角标 | Web 读取现有成员资料；Native 读取 RTC 名称、在线和设备状态，不伪造房主权限 |
| 控制栏 | 圆形图标、激活/禁用状态、未读数、退出按钮、设备菜单插槽 | Web useTrackToggle、设备选择与偏好保存；Native 主持人邀请/主动采集/退出确认 |
| 聊天 | 消息列表、气泡、输入框、发送按钮、空态、错误与工具插槽 | Web 保留上传、下载、文件管理；Native 保留确认重试、历史恢复，文件仍提示到网页查看 |
| 成员与更多 | 成员列表、设备指示、菜单行和统一面板 | App 提供成员、举手、分享名称及获授权设备操作；Web 高级管理、录制、设置与 AI 沿用原入口 |
| Web 嵌入卡片 | 同一舞台中的插槽、分页与焦点布局 | 原播放器、添加卡片与其权限/状态仍由 Web 管理；分页和焦点切换保留播放器挂载 |

主色仍为 `#22CCEE`。Web 控件使用 Ant Design，App 控件使用 Ant Design Native；共同注入 Button / Icon / Input 端口。Native 不引入 DOM、Web CSS、浏览器 Canvas 或 Web 的 LiveKit 包。

## 代码边界

- `packages/meeting-core`：可序列化 tile 数据、分页/焦点、可用舞台尺寸和稳定头像颜色。
- `packages/ui`（`@vocespace/ui`）：统一共享 UI 包，提供主题色、图标、按钮/输入框端口及会议与设置组件。
- `packages/ui/src/meeting`：PhoneMeeting、MeetingControls、MeetingChat、MeetingMembers、MeetingMenu；视图状态放在 usePhoneMeeting。
- Native `useSharedMeetingRoom` / Web `useSharedMeeting`：映射 RTC 和业务状态；Web 设备 actions 由 useSharedControls 生成。共享组件不请求 API、不创建 Room、不订阅 Socket、不采集媒体。
- 关闭面板保留聊天挂载和草稿；离线可编辑草稿，离线/发送中/空白内容不能发送。Web 输入保留 Shift+Enter 和 IME 组合输入保护。
- App 软键盘由稳定外壳处理，避免双层 KeyboardAvoidingView 重复补偿；Android 返回先关闭当前会中面板，再沿用会议退出保护。

## 仍需继续的范围

目前是 Web Phone 风格的共享基础会中 UI，还不是原界面逐像素复刻。头像使用跨端基础图形，尚未共享原 AVO 的物理动画、自定义角色、Live2D；Native 未添加播放器、白板、屏幕发布、文件上传、录制管理或房间设置能力。Native 不展示无法执行的这些动作。后续应逐项确定能力边界后扩展适配器。

本轮回归重点：

1. 在实际 App 加入同一测试 Space，确认双列卡片高度、头像、发言状态、静音图标和文字截断；检查 1 / 2 / 4 / 6 人、共享屏幕与横屏。
2. 打开/关闭成员、更多和聊天；检查中文键盘、安全区、草稿、断线重连、举手和邀请后的主动采集。
3. Web 共享入口检查设备菜单、文件上传/下载、播放器分页和放大、设置/录制/AI；未带参数的 Web Phone 和 PC 应继续使用原界面。
4. 开麦/开摄像头时退出、切 Tab、Android 返回的确认，以及后台释放连接。

当前四 Tab 保留。公开发现、上下滑动、实时预览和延迟加入仍属于 checklist 4.5，不能用本地界面预览代替。
