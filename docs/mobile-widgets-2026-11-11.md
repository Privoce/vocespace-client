# 手机个人应用面板与广场空态

Platform 手机广场在成功读取且没有活跃房间时显示“当前没有活跃的 Space”，不再显示插图。读取失败保留错误状态，不将失败描述为空目录。

## 共用布局

`packages/ui/src/meeting/MeetingAppsPanel.tsx` 提供横向页签、应用卡片、标题操作槽和折叠布局。Web Phone 的 `FlotAppItemPhone` 和 Native 的 `ParticipantApps` 使用同一个组件；页签切换/折叠保留内容挂载与草稿。Web 原有待办、团队、倒计时业务组件继续放入内容槽，PC 分支保留。删除 Phone 样式对所有后代 Collapse 的隐藏规则，防止未展开的团队成员行消失。

Native 内容适配器提供今日完成/待办列表、添加/修改/完成/删除、完成历史、共享开关、团队进度、倒计时和计时器。时间输入使用原生文本控件，待办复制入口使用系统分享面板，可由用户选择复制文本；没有新增原生依赖。没有新增后台倒计时通知或 Native 完成提示音。

## 自身数据与授权

旧 Native 目录只有公开应用的只读投影，无法显示自己的隐藏待办、未公开倒计时，也不提供写入。新增 `/api/v1/native/widgets`：POST 读取自身快照，PUT 接受受限动作。身份来自 Native 会话和已确认 joinId，客户端不能指定另一名参与者；未启用的应用拒绝写入。

沿用 `space:<name>` 内 appDatas、sync、Todo 分组数据；完成任务删除仅隐藏，未完成任务删除移除。添加使用稳定任务 ID 去重，计时暂停/续接由服务端时间计算。数据通过 Redis CAS 写入，并原子检查会话、joined 状态和撤销标记；不改其他参与者或私密子房间的数据。当前 Native 编辑保存到会议 Space，未增加 Supabase 账号待办同步。

团队只显示当前公共 Room 中原目录允许读取的公开待办，自身数据可显示自己的未共享可见待办。对其他成员仍只读，不因 UI 共用而授予管理权限。异步读取有取消和代次保护，不覆盖新写入或新房间；旧服务端无法读取时保留已知页签和未读取提示，不填充假数据。

## 验证与边界

- 173 项测试通过，其中新增 9 项覆盖身份隔离、撤销、CAS 冲突、任务去重/完成历史、计时续接、非法动作、旧读取覆盖及切换身份取消。
- Web / Mobile / UI / API / Platform 类型和导入边界通过。Widgets 目录 lint 无新增错误，其他既有文件保留原 Hook 警告。
- API 构建、iOS Expo JS 导出通过；已有 Web dev 服务运行中，本轮未覆盖其构建目录。
- 浏览器隔离场景使用真实共享布局和 Native 视图、注入测试数据，验证三个页签及待办/团队/倒计时呈现；不是线上 API 或真机功能验收。
- 本轮未发布服务器或手机安装包。App 当前请求线上服务，新增自身应用读写需要发布 API 后才能联调；Native 键盘、系统分享、跨端同步仍需设备回归。
