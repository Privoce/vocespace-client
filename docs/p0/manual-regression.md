# 双浏览器入会与退出回归步骤

日期：2026-09-15。状态：**步骤已建立，真实双端执行尚未进行**。P0 交付可执行本地测试和本手册，不宣称真实媒体通过。执行结果使用下方模板登记，不能预填通过。

## 1. 前置条件

- 独立测试实例，使用自定义 server.js 启动，并有可用的 LiveKit 配置；不要对现有生产空间执行测试。
- 两个独立浏览器或用户配置目录 A/B，使用不同测试昵称，避免共享 localStorage；至少一组实际不同设备以确认远端媒体。
- HTTPS 或受浏览器信任的 localhost；摄像头/麦克风可用，权限可重置。为避免回声使用耳机。
- 明确测试空间/频道、管理员与普通成员身份，记录浏览器和系统版本。
- 如验证断网，分别区分 Socket.IO 信令与 LiveKit 媒体；浏览器开发工具的 HTTP Offline 不保证 WebRTC 真断开。
- 日志和截图不包含真实 token、用户内容或凭据。录制、AI、S3 不是本基础流程前置条件。

## 2. 操作与预期

| ID | 操作步骤 | 预期结果 |
|---|---|---|
| M01 | A 打开测试空间，B 打开同一地址 | 两边进入当前预览/入会流程，无异常无限加载 |
| M02 | A 选择昵称与设备，允许权限后加入 | token 请求和 LiveKit 连接成功；设置与设备选择符合现有行为 |
| M03 | B 加入同一空间/频道，双方打开音视频 | 双方能看见/听见远端，成员列表正确；不是仅出现本地预览 |
| M04 | A 依次关闭/打开麦克风、摄像头，切换可用输入 | B 观察到真实媒体变化；A 偏好/控制状态一致，无重复轨道 |
| M05 | A 开始共享屏幕，B 查看，再由 A 停止 | 共享真正发布与结束；摄像头/麦克风不被误停 |
| M06 | A 向 B 发一条非空文本；B 关闭聊天后再收到一条 | 文本各显示一次；未读按当前规则更新；重新打开聊天状态正确 |
| M07 | A 提交全空格文本；随后提交一个小测试附件 | 空文本不发送；附件显示一次，可访问；自身附件不增加未读 |
| M08 | A/B 切换同频道/不同频道 | 音频及权限符合当前频道策略；不同频道相机/屏幕可能仍可见，不能当成新缺陷 |
| M09 | 在 A 已加入时刷新或关闭，选择取消/留在页面 | 有退出确认；保留会议，随后页面可见时卸载尝试被清除 |
| M10 | A 点击应用离会按钮 | 离会 API/清理/Socket 断开/返回首页按现有流程；B 最终看到成员离开 |
| M11 | A 不刷新整站，再次加入原空间，重复发消息 | 能重入；消息不重复；设备状态正常；如失败记录为已有问题 |
| M12 | A 暂时断网再恢复，持续记录 B 的成员与媒体状态 | 分别记录 Socket 和 LiveKit 恢复；没有重复消息/业务动作；失败保留证据 |
| M13 | A 断开较长时间并最终离开 | 记录服务端延迟清理和成员状态；不能只凭 5 秒计时判断通过 |
| M14 | 拒绝设备权限或断开外设，再按页面提示恢复 | 错误可见；可以恢复或明确告知不支持，不残留无主采集 |
| M15 | 用测试平台生成的合法直入参数加入 | 保留平台认证、预览跳过与参数清理行为；不手工伪造生产 token |
| M16 | 打开 Dashboard，检查原有配置和列表读取 | 页面与读取行为正常，不执行删除/重置操作，不改变其结构 |
