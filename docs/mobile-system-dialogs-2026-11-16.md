# Mobile 系统界面误触发退会（2026-11-16）

用户真机反馈首次允许麦克风/摄像头权限、屏幕共享及选图/文件时断联。

## 定位与修改

`useConference` 原先在 AppState background 时立即退出；独立媒体订阅也会在后台且没有屏幕轨道时退出。系统 Activity、权限或广播界面进入后台，以及系统 Promise 先完成、AppState 后恢复的时序，会命中这些退出路径。文件选择器此前没有保护范围。

- `system-interaction` 为主动打开的系统界面记录可重叠的操作范围，覆盖 NativeRoom 的开启采集（含 iOS 广播选择器）和共用 `pickDocument`。
- 成功、拒绝、取消和异常均通过 finally 释放；结束后保留 1.5 秒恢复窗口，防止 AppState 恢复比 Promise 晚。范围只覆盖系统调用，不覆盖之后的文件上传网络请求。
- `background-policy` 统一 AppState、媒体变化和系统操作完成的判断，移除重复退会分支。恢复窗口结束后若真的仍在后台，普通会议继续沿用退出规则。
- 屏幕广播已启动时保留会议，暂停摄像头/麦克风；后台广播停止后退出。避免媒体 sync 回调重复触发暂停，清理订阅后忽略迟到回调。
- 显式离开、撤权与 NativeRoom 原有采集代次/停止逻辑继续生效，保护范围不代替采集授权。

## 验证与限制

新增 8 项生命周期测试：麦克风、摄像头、屏幕、图片和文件的后台/恢复竞态；失败后真实后台退出；广播继续及结束；重叠操作与已卸载策略不再触发退出。

全量 49 个测试文件 / 186 项通过，全项目与 Mobile 类型、依赖边界、差异检查通过。iOS Expo JS 导出至临时目录成功；未生成 IPA/APK、未发布，不等于真机验收。
