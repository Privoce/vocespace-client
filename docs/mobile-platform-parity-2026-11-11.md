# 2026-11-11 手机主页、会议工具与文件入口

## 实现

- Platform 使用和 Web Phone 相同的 `max-width: 767px` 断点；手机首页提供广场和底部个人中心。个人中心复用现有账号服务，接入注册/登录、头像与昵称、个人会议房间、浏览偏好、反馈及协议入口。桌面首页和他人资料页保留原分支，断点变化不清空手机页状态。
- 手机广场仅展示 LiveKit 当前开放且业务策略允许公开发现的 Space；沿用合并 Supabase 目录元数据的服务。离线目录卡不会被当成实时预览源。播放通过 Platform 同站代理和 HttpOnly 浏览器会话签发短期 HLS 租约，切 Tab、滑动、后台和退出释放播放器与租约。
- Web Phone / Native 共用 `MeetingToolFolder`：可容纳时展示完整触控图标，空间不足时显示缩略文件夹，点击展开。桌面 Web 工具保持原呈现。
- Native 工具通过确认入会后的专用接口访问同一份 `uploads/<Space>/<Room?>/tile_players.json`。提供图片、HTTPS 页面、HyperBeam、白板、聊天入口；白板使用原广播格式，关闭面板后保留当前会话内笔迹。连接、媒体及账号状态不进入共享 UI。
- 两端聊天输入行左侧增加 `+` 上传和文件列表图标。Native 使用 HTTP 上传，身份由服务端会话解析；稳定消息 ID 去重，失败保留附件供重试，换房取消迟到请求。下载 capability 有效期 120 秒，每次下载重新验证会话和入会权限。

## HLS 排查证据

用户确认故障发生在生产 `vocespace.com` 的 iOS App，表现为只有房间插图、没有预览状态。用户保持 `test` 房间开放后，使用独立 Native 预览会话复测，未创建正式业务成员或 RTC 连接：

- `/api/platform/spaces` 返回 `test`，公开成员数为 1。
- 预览接口由 starting 转为 ready；播放列表及 MPEG-TS 切片 HTTP 200。
- Egress 的实际 S3 路径与服务端读取路径一致；无证据支持修改路径前缀。
- FFmpeg 成功解码 H.264 Main / AAC-LC、720×1280 主会场画面，包含 Admin 占位卡；连续读取播放列表和片段成功。
- macOS Apple AVPlayer 使用新签发的有效租约连续播放约 12 秒，无播放器错误。早先过期租约返回 410，属于预期权限过期，不能作为 iOS 故障证据。
- 已通过 Device Hub 实测连接的 iPhone（iOS 18.3.1、App 1.0.0 (2)）：经用户同意临时关闭自动加入，进入广场后先出现加载状态，随后显示与解码结果一致的 Admin 占位画面，状态变为“正在播放”。全程未正式入会；测试后恢复自动加入为开启并返回首页。原始“持续只有插图”的故障本次未复现，不将这次成功描述为已定位并修复全部间歇问题。

截图证据保存在本机 `/tmp/vocespace-ios-hls-20261111.png`。

代码补充：播放器失败时及时卸载源、释放租约并停止续租；媒体出口支持 HEAD；S3 权限/连接错误返回 `PREVIEW_STORAGE_UNAVAILABLE`，仅对象尚未生成时返回 starting，避免无限假加载。

## 验证与发布边界

- Platform 浏览器验证了 390px 页面、767px 手机 / 768px 桌面边界、个人中心偏好弹层和注册入口。
- Web、Platform、API 生产构建通过；API JSON 部署检查通过。Lint 仍有仓库原有 Hook / img / JSON 导入警告，未通过关闭检查绕过。
- 根、API、Mobile、共享 UI、Platform 类型及导入边界检查通过。
- `pnpm test`：41 个测试文件、161 项通过；Platform 账号流程另有 6 项通过。新测试覆盖跨站拒绝、Native 身份不可伪造、入会权限、下载失效、并发上传去重、换房迟到结果、浏览器 Cookie 隔离、HLS 存储错误和媒体二次权限校验。
- iOS / Android Expo JS 导出通过；新增 `react-native-webview` 需要重新构建原生 App。JS 导出不等于新 IPA/APK、真机工具和文件互通验收。

## 工具卡片后续修正

用户反馈工具文件夹能展开但出现“工具操作失败”。确认本机 Mobile API 指向线上；使用独立临时 Native 会话探测 `/api/v1/native/tools`，返回 403 `NATIVE_ENDPOINT_REQUIRED`，说明线上请求仍落入旧版通用接口授权逻辑，尚未部署新增 Native 工具路由。诊断会话随后撤销，未加入会议。展开菜单只涉及本地 UI，不能证明工具列表或创建接口可用。

共享工具卡片去掉内层灰色小容器及 0.6 倍缩放，直接使用整个 tile 排列图标；小尺寸仍由整个 tile 打开展开面板。按用户后续要求，tile 内完全移除列表和操作错误提示，失败时保留现有工具列表并后台轮询重试，错误不占用 tile 高度；工具详情弹层仍可显示操作错误。工具请求保留 HTTP 错误码，图片上传使用 RN FormData 支持的 append。共享聊天输入栏和两端附件按钮组统一 flex 垂直居中，修正图标与输入框中心线不齐。

Mobile / UI 类型及边界检查通过；3 项 Hook 回归随最新要求更新，覆盖错误不进入 tile、轮询恢复与换房迟到错误丢弃。共享组件在浏览器隔离场景验证充足/不足空间布局和展开入口；没有将此视为线上工具功能或真机完整验收。线上 API 仍需发布更新。
