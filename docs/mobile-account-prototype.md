# Mobile 登录与“我的”界面（2026-10-19）

本批按用户四张设计截图实现，只修改 Native App。Web Phone 与 PC 保留既有入会方式；本次登录、注册、个人主页不推广到 Web。

## 入会与身份

- Native 不再显示 PreJoin，也不在入会前采集媒体。首页随机/指定 Space、“我的会议房间”和会议列表手动加入直接走已有创建/prepare/RTC/confirm；预览仍在连续有效播放 15 秒后加入。
- 已登录使用本机资料昵称，访客使用原本机昵称。麦克风与摄像头初始关闭，发布仍由用户在会中主动触发并经过原服务端授权。
- 会议连接所有者继续位于 Tab 之上；主持人、发布媒体等离开确认与后台清理保留。退出演示登录先完成会议退出；取消离开则保留登录。
- 此处是 UI 演示身份，不是真实账号认证；不会替换 Native API 的 SecureStore 会话，不向服务端传送演示密码，不用演示 UID/会员级别授予任何权限。

## 配置与使用

`apps/mobile/.env.local`（本机文件）和 `.env.example`（模板）使用：

```dotenv
EXPO_PUBLIC_DEMO_EMAIL=syf@outlook.com
EXPO_PUBLIC_DEMO_PASSWORD=test001
```

缺省值相同。Expo 的 `EXPO_PUBLIC_` 值进入客户端包，仅供当前 UI 原型，不配置生产用户凭据。改动后重新启动 `pnpm dev:mobile`；不涉及新的原生依赖。

首次打开显示登录页，支持切换注册 UI 或以访客浏览。登录与注册均校验上述固定演示账号，不新建真实账号。默认邮箱预填，密码由用户输入。“记住我”只保存账号标记，不保存输入密码；关闭后登录只保持本次运行。退出登录清除标记，本机资料与偏好保留。

## 已实现与演示边界

- 暗色布局、青色主色、品牌、登录/注册表单、游客入口；复用 Ant Design Native 控件。
- “我的”未登录/已登录两种状态：资料、统计卡、会员展示、会议房间、内容库、通用设置、退出登录。
- 编辑昵称、本机通知/手势偏好保存、原会议预览静音/自动加入设置、复制和系统分享可用；快速开会复用现有创建/加入流程。
- UID、房间号 `882-4417`、等级、会员、关注数/粉丝/获赞/时长、内容库数量是设计样例；不是后端账户数据。快速开会把样例房间号作为普通 Space 名处理，不赋予该名字固定所有权。“空闲”也只是原型展示。
- 通知与手势开关仅保存偏好，没有注册推送或启动手势识别。Gmail OAuth、找回密码、服务协议、内容库、真实会员/存储权益均未接入，点击显示说明，页脚标记演示数据。
- 头像使用本地矢量占位；未登录内容库通过弱化显示锁定。没有加入新头像上传或模糊库。
- 新增文案进入 `packages/i18n` 的中、英、俄词典。逻辑位于 `apps/mobile/src/account`，界面位于 `screens/AuthScreen.tsx` 和 `ProfileScreen.tsx`。
- 2026-10-20：Web Icon 剩余资源统一迁入 `@vocespace/ui`，Web/Native 保留各自薄渲染适配。登录/注册页使用原 `logo2`（含字标）和四色 `google`，Email 使用 Native `MailOutlined`；iOS 模拟器已确认图形与渐变正常，186 组 Web 图标渲染对照一致。

## 验证

- 202 项 Vitest 测试通过，包括演示凭据拒绝、记住/不记住登录、恢复/退出、持久化失败、资料保存与坏数据隔离。
- 根、Mobile、UI、API 类型检查和工作区依赖边界通过。
- Expo iOS/Android JS 导出通过；不代表真机媒体或真实账号服务已验收。
- iPhone 16 Pro / iOS 18.3 模拟器已检查登录/注册、登录后主页、刷新恢复登录、资料弹窗保存、退出与游客内容库。视觉检查修正了保存按钮翻译键，并调整首屏间距使游客入口更易见。
- 真机键盘、小屏/大字体、登录后新建/加入会议、会中昵称和退出确认需继续回归。

后续真实用户体系应替换 account hook 的存储/认证适配，接入服务端会话交换、资料/统计、个人会议号、OAuth 与注销；不能把本机标记直接当成业务授权。
