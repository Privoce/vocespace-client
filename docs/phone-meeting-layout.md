# Phone / Mobile 会议布局（2026-10-21）

## 实现范围

Web Phone 和 Native 复用 `packages/ui/src/meeting/PhoneMeeting.tsx`。默认网格每页最多四张 Tile，排列为两列；只有一张时占满宽度。聊天 Dock 和屏幕共享不再自动把第一张 Tile 切成聚焦。PC 的布局分支不变。

顶部 Header 提供网格 / 聚焦切换。点击 Tile 的聚焦按钮选中该 Tile，主卡片上方展示，下方每页最多两张小卡片；主卡片的网格按钮返回它所在的网格页。点击 Header 聚焦会选中当前页首张 Tile。被聚焦成员离开后回到网格，人数变少时页码收敛。Tile 的形象点击、全屏、应用和举手入口继续使用已有端内适配。

布局区域下方、聊天 Dock 上方固定分页器，显示页码和可点击圆点；多页时支持左右滑动，前后按钮用于替代手势。水平距离至少 64 且大于垂直距离的 1.5 倍才翻页；短拖、回拖、多指和被取消的手势不提交。长列表最多显示七个邻近圆点，所有页都可通过滑动/前后按钮访问。短屏允许布局区域纵向滚动，避免 Tile 和工具被压扁。

Native 会议内横向滑动现在用于布局分页，停用旧的横滑换 Room 捕获；Room 仍通过 Channel Drawer 切换，沿用退出确认和会话切换流程。Space 的纵向浏览逻辑保留。连接所有者不随布局或页码变化，主卡片在下方分页时保持挂载；嵌入播放器在翻页、网格/聚焦切换时保持同一父层和 key。

## 验证与边界

- 完整测试 45 个文件、223 项通过；单元 / UI 测试覆盖：默认四宫格（包括聊天 Dock 与共享屏幕）、顶部切换、Tile 聚焦、返回当前页、人数减少/被聚焦成员离开、媒体节点保持、嵌入播放器与聊天草稿保持。
- RN Web 事件测试覆盖鼠标和触摸翻页，以及短拖、回拖、触摸取消；纯规则验证方向阈值。
- 根 / Mobile / UI 类型检查、共享包边界、相关 Web lint、iOS 与 Android Expo JS 导出通过。
- 浏览器 390×844 静态预览验证四宫格、分页器点击、Header 与 Tile 聚焦；预览数据不连接真实会议。
- 真机触摸手感、AVO 与真实音视频同时运行时的体验仍待用户回归。JS 导出不代表原生编译或设备验收。
